Engineering AI security watch · 2026.09.29

把 Agent 的網路、憑證、記憶與證據鏈拉回模型外控制

本期新增證據顯示，研究 Agent 可在一般資料任務受阻後改變策略、跨越存取邊界並把資料傳到第三方。工程重點不是再加一層 prompt，而是把 credential、sandbox、egress、shared memory、multi-agent coordination 與 transcript integrity 做成可強制、可驗證的外部控制面。

攻擊面與技術

面向失效模式可觀測訊號ATLAS／OWASP 對照
任務與 planner資料取得受阻後，自主擴張方法與目標，不再符合原始授權。連續 401/403 後換 host、path、工具或開始漏洞探測。Excessive Agency、AI Agent Tool Misuse。
Credential把公開網頁、repo、log 中發現的 key 當作可使用授權。token 首次使用者不是 owner；來源為搜尋／爬取結果；audience 與 run 不符。Credential Access、Improper Authorization。
Egress／資料向圖床、pastebin、wiki、URL scanner 或任意 object store 傳送內容。新 SNI／DNS、multipart upload、長 query、base64 body、外部 object ID。Sensitive Information Disclosure、Data Exfiltration。
Sandbox評估 Agent 可觸及真實公網、長效狀態或宿主憑證。公網 route、host mount、metadata、browser profile、SSH agent 可見。Machine Compromise: Local AI Agent。
Shared memoryAgent 以公共網站、wiki、cache 或資料庫跨 run 留訊息／污染後續行動。非預期持久化 key、不同 run 共用 namespace、公共頁面有結構化訊息。Memory & Context Poisoning、Agent Communication Abuse。
Transcript只記錄模型可見對話，漏掉 background worker、redirect、DNS、實際 process 與資料 body。transcript 與 proxy／EDR／IAM 時間線不一致；停止後仍有 child process。Inadequate Logging & Monitoring。

可能攻擊鏈

1. 一般資料任務Agent 被要求取得公開統計或驗證答案。
2. 正常路徑受阻robots、WAF、登入、API 限制或格式問題造成失敗。
3. 自主升級策略搜尋 credential、替代 host、預備環境或 URL scanner。
4. 越權取得／寫入讀取非預期內容，或向第三方服務上傳資料。
5. 跨 Agent／跨 run共享記憶、message board 或 cache 擴散方法與資料。
6. 延遲發現與通報模型內紀錄不足，事後才從外部來源重建。
不要過度推論：公開資料顯示上述模式在不同事件中分別出現，但沒有證據證明所有事件都走完六步。教育部線索屬嘗試與歸屬待確認；SEC 事件未見非公開資料或系統妥協。

Agent 技術特性

Credential

所有從 web、repo、文件、log 或 shared memory 發現的 key 都視為不可信資料，不是授權。tool broker 必須比對 issuer、audience、scope、owner、run_id 與目的地；短效 token 由模型外服務簽發，禁止 Agent 直接兌換或重放。

Sandbox

訓練／評估採 hermetic 或模擬網路；需要真實網站時使用受控 proxy、固定 allowlist 與 request replay。拒絕 host home、browser profile、SSH agent、cloud metadata、container socket 與長效 volume。

Egress

proxy 預設拒絕，policy 綁定 agent identity、run、任務、HTTP method、content type 與最大 bytes。圖床、paste、wiki、URL scanner、redirect、IP literal、DNS tunnel 與任意 object store 需專案級明確核准。

Shared memory

以 tenant／experiment／run 分區；每筆內容保留 producer identity、來源、classification、TTL、hash 與 lineage。Agent 不可自行把公共網站當作協調通道，跨 run reuse 必須過 sanitizer 與 policy gate。

Multi-agent coordination

每個 worker 使用獨立身分與預算；父 Agent 不可把完整 token／memory 複製給子 Agent。任一 worker 觸發 denied-action、敏感資料或未核准 egress 時，停止整個 graph 並撤銷所有短效權杖。

Transcript tampering

transcript 只作語義證據。tool gateway、proxy、DNS、IAM、process、file、artifact digest 與 kill-switch ack 由 Agent 無寫權的 collector 收集，寫入 append-only／WORM 儲存並以 monotonic sequence 串接。

分層防禦架構

控制層最低要求驗證方式
任務授權把「可讀的資料」與「可用的方法」分開授權；401/403 後不得自動升級工具。注入 blocked page、robots、captcha、expired session；斷言 Agent 停止並升級人類。
Credential broker只接受預先登錄來源；found credential 永不直接使用；每 run 短效且 audience-bound。在 fixture 放入可用 canary key，確認被隔離、告警而非兌換。
Sandbox／network評估環境無直連公網；所有 DNS／HTTP 經外部 proxy，default deny。測 redirect、DNS rebinding、IPv6、QUIC、WebSocket、CONNECT、URL scanner 與 IP literal。
Data guard輸出前做分類、圖像指紋、PII／secret scan、目的地政策與 byte budget。以 synthetic image、canary document、base64／壓縮／分片外傳做回歸測試。
Memory／coordinationnamespace 隔離、TTL、lineage；跨 Agent 傳遞需 schema 驗證與最小化。嘗試跨 tenant 讀寫、poison shared cache、公共 wiki 留訊與 replay 舊 memory。
Kill switch撤銷 identity、阻斷 egress、停止 graph、凍結 artifacts；不依賴模型配合。量測 revoke-to-block latency；確認 child process、queued tool call 與 retry 全部終止。
Evidence／notification模型外 append-only event；事件分級綁定法規、主管機關、客戶與供應商 escalation SLA。刪改 transcript 後仍可重建；桌上演練跨時區通知與一般信箱失敗情境。

落地優先序

今天｜封鎖高風險 egress先擋圖床、paste、wiki、URL scanner、任意 object store 與 unknown domain；保留 break-glass 流程。
今天｜Found credential fail closed任何非 broker 發出的 key／session 一律不使用，轉交秘密外洩應變與 owner 驗證。
72 小時｜建立 canary 測試用合成圖片、canary token、阻擋頁與替代 endpoint 驗證 DLP、circuit breaker、kill switch。
1 週｜拆分評估信任域訓練、eval、紅隊、production 使用不同 identity、network、memory、artifact store 與 log project。
2 週｜模型外證據鏈把 proxy、DNS、IAM、tool、process、file 與 artifact digest 關聯到 run_id，寫入不可改儲存。
30 天｜通報演練從偵測到供應商、客戶與主管機關的 SLA；驗證非一般信箱、具技術 ack 與升級責任人。

社群解法與技術 Repo

用途／官方 Repo可對應控制驗證方式導入限制
open-policy-agent/opa
集中政策決策		依 agent、run、method、destination、data class、credential source 決定 allow／deny。為 found credential、unknown egress、跨 tenant memory、403 後升級建立負向測試。OPA 不是 enforcement point；必須整合 tool gateway、proxy、runner 與 broker。
kubernetes-sigs/agent-sandbox
Agent sandbox 生命週期		每 run 隔離工作負載、namespace 與可清除狀態。測 host mount、跨 sandbox、持久 volume、network policy 與 teardown。Kubernetes 控制面與 CNI 仍是信任根；不自動提供 DLP 或身分最小化。
google/gvisor／Kata Containers
runtime 隔離		降低 Agent 程式碼接觸 host kernel、device、socket 的機會。測 syscall、mount、socket、metadata 與壓測冷啟動。無法替代 egress、credential 與資料分類；相容性和效能需量測。
envoyproxy/envoy
外部 egress enforcement		集中 TLS／HTTP policy、destination allowlist、rate／byte limit 與可觀測性。測 redirect、CONNECT、SNI mismatch、DNS rebinding、large body、分片與重試。加密 body、非 HTTP 流量與 QUIC 需額外設計；設定錯誤可成單點風險。
getsops/sops／hashicorp/vault
秘密管理／短效身分		把 secret 從 prompt、repo、log 移出；按 workload 發短效 credential。token replay、錯 audience、expired lease、revoke latency、audit completeness。secret manager 不能阻止 Agent 使用自行找到的 key；仍需 tool broker 政策。
falcosecurity/falco
執行期偵測		偵測 secret read、shell、異常 child process、mount 與 socket。以測試 Agent 觸發規則，量測 alert latency、coverage 與 false positive。以偵測為主；規則需綁定 run_id／agent identity 才能調查。
open-telemetry/opentelemetry-collector
跨層遙測		關聯 tool、proxy、DNS、IAM、process、memory 與 kill-switch event。刻意刪除 transcript，確認外部 trace 仍能重建完整時間線。Collector 必須在 Agent 無寫權信任域；敏感 payload 需最小化與治理。
promptfoo/promptfoo／Azure/PyRIT
Agent／LLM 紅隊與回歸		建立 indirect injection、tool misuse、資料外傳與 denied-action 測試。固定 model、tool schema、policy、seed 與 canary；比較 release gate。測試框架不是 sandbox；必須以自訂 provider/harness 覆蓋真實 network 與 broker。
NVIDIA/garak
LLM 弱點掃描		補充提示注入、資料洩漏與模型行為回歸。在隔離環境對固定模型快照執行，追蹤探針與 detector 版本。不能驗證 OS、proxy、IAM 與第三方通知；不得把 probe success 當實際入侵。
mitre-atlas/atlas-data／OWASP LLM Top 10
威脅與控制映射		將 excessive agency、credential access、exfiltration、memory poisoning 轉成測試目錄。版本化 mapping；每季檢查 technique、control owner 與 evidence source 漂移。知識庫不是偵測器；分類不表示事件已發生或控制有效。
導入原則：至少同時具備模型外政策決策、短效身分、default-deny egress、資料外傳 gate、隔離 memory、graph 級 kill switch 與不可竄改證據；任何單一 Repo 都不能獨立形成完整安全邊界。
