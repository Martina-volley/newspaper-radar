AI 資訊安全報 · 2026.11.02 · Asia/Taipei

託管平台金鑰遭濫用，Agent 攻擊再現

查核截至 11/02 18:31；主要窗口 10/30 18:31–11/02 18:31。前期截止 10/30 18:29 至本窗起點約 2 分鐘，已檢查事件更新。

本期焦點

Northflank 10/30 公告重大安全事件，要求所有用戶假設環境變數已被解密並立即輪替。官方狀態頁記錄多名用戶回報存放於平台的 AI API 金鑰遭未授權使用；這是用戶回報，調查尚未給出逐戶鑑識與總受害數。另一事件中，Chainalysis 10/30 承認外部行為者以「offensive agentic techniques」未授權進入其系統與內部工具，並確認部分基本用戶資料遭存取。

前期漏列的 Cursor 10/29 擴充套件事故，本期有關鍵修正：10/30 官方把受影響版本從 2.1.313 擴為 2.1.312／2.1.313。這是惡意套件嘗試安裝 SSH 後門，不能把嘗試等同成功控制所有可能受影響端點。

發生什麼

10/29｜事發、前期漏列Cursor 市集在 09:27–20:35 UTC 提供遭修改的 Claude Code 擴充套件。惡意碼收集主機資訊，嘗試寫入 SSH 公鑰、啟用服務與反向隧道。Cursor 稱最多 5,000 名用戶可能受影響，並指出普通權限下後門步驟多半因程式錯誤而失敗。
10/30 11:43 UTC 起｜Northflank 偵測Wiz 發出警訊，Northflank 隨後修補網路政策；13:40 UTC 起公開調查，23:38 UTC 更新指出用戶回報 AI API 金鑰遭未授權使用。10/31 起陸續開放資料庫及訊息服務密鑰輪替。
10/30｜Chainalysis 披露公司稱本月偵測外部攻擊者使用 agentic 技術存取內部系統與工具；已發現基本用戶 ID、姓名、電郵與組織角色標籤遭存取，仍在釐清個別紀錄。
10/30｜Cursor 更正與 Wiz 研究Cursor 於 11:30 PT 修正版本範圍與 IOCs。Wiz 公布 10 月至少九家 AI 開發平台事故的整理與兩宗 Bedrock 金鑰下游濫用案例；九案不能直接推為同一攻擊者。

為什麼重要

  • Northflank 的應變指引涵蓋 workloads、secret groups、global secrets。只在平台內替換儲存值並不足夠；必須在金鑰發行端撤銷舊憑證。
  • Wiz 在兩宗可歸因於平台外洩的企業 Bedrock 金鑰案例中，看見約 80 萬與 170 萬次呼叫；這是兩個案例，不是 Northflank 或九家平台的總量。
  • Cursor 事件說明套件名稱與版本看似官方，仍需核對下載來源及成品雜湊。其惡意版本並非 Anthropic 製作。

Agent 行為痕跡

Chainalysis 官方使用「offensive agentic techniques」描述攻擊，但未公開任務鏈、模型、工具呼叫或自主程度，暫不能細化成多 Agent 全自動入侵。Northflank 與 Cursor 事件目前有憑證濫用、惡意擴充套件的證據；並無足夠資料證明 Agent 是兩案的實際入侵執行者。Wiz 的「agentic attacks」是跨案分析框架，應與各事件方確認分開。

對企業的影響

Northflank 用戶：清點平台儲存的所有環境變數與外部服務金鑰，在發行端撤銷後重發；核對 AI 供應商使用量、帳單、登入與 API 日誌，並保存異常呼叫證據。Cursor 用戶：查 10/29 時段是否由 Cursor 市集安裝或更新 macOS／Windows Claude Code 2.1.312／2.1.313；對照官方 IOCs 與清理指引。Chainalysis 用戶：提高密碼重設與 MFA 提示警覺，等候個別通知。

我們應追蹤什麼

  • Northflank 最終初始入口、實際被解密祕密的範圍、逐戶通知與服務恢復。
  • Chainalysis 攻擊者使用的 agentic 技術原始證據，以及基本用戶資料的個別影響範圍。
  • Cursor 受影響者直接通知、成功植入後門的實際數量，以及其後市集供應鏈修補。
  • 前期 PHP2Shell／PAN-OS 事件的台灣正式通報、修補及鑑識；資安署已就網通設備管理介面風險發布提醒，沒有公開台灣受害名單。

3 句結論

  1. Northflank 的平台事故已導致用戶回報 AI API 金鑰遭未授權使用，所有存放於該平台的祕密應按官方指引輪替並查帳。
  2. Chainalysis 確認外部行為者以 agentic 技術進入內部工具與取得部分基本用戶資料，但具體 Agent 攻擊鏈尚未公開。
  3. Cursor 惡意擴充套件的受影響版本已更正為 2.1.312 與 2.1.313；後門是已執行的嘗試，成功登入受害機仍待證據。
