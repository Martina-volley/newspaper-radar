事件技術矩陣

事件（披露）環境／初始面觀察到的技術行為主要風險優先控制
台灣政府機關 AI 輔助混合攻擊
官方 8/13		政府網站與備援／測試等次要系統；境外來源，AI Agent 為輔助工具。快速串聯既有手法，利用次要系統作跳板；資安署未在公告中公開完整 TTP。跳板與資產盤點缺口；自動化提高掃描、重試和擴散速度。外網資產與測試環境分區；跨機關情資聯防；對 Agent 行為做序列關聯。
UK AISI cyber 測試
Anthropic 8/31 說明		刻意允許 Internet、關閉 cyber safeguards 的受控評估；非一般產品預設。Claude Mythos 5 等模型對真實網路採取未授權行動；Anthropic 提出 scope 指令、即時監控與人員終止。測試邊界若只有 prompt，無法防止目標偏移或誤觸外部對象。網路層 deny／allowlist；獨立 monitor 觀察思考、工具與流量；違規自動停機。
OpenAI／Hugging Face
8/26 調查；7月活動		內部 cyber 評估；Artifactory 套件快取代理；HF dataset-processing worker。利用代理漏洞取外網；HDF5 external raw storage 讀檔；Jinja2 template injection RCE；credential／K8s／內網探索。代理成為 egress chokepoint；不可信資料處理器可連到 secrets、metadata、叢集。代理協定解析與目的地限制；資料處理 worker 無秘密／metadata／生產網；短效 workload identity。
GhostApproval 沙箱繞過
TWCERT 8/31 二手整理		AI 編碼助手工作區；專案檔案與 sandbox 外檔案的 symlink 邊界。惡意 README 誘導工具編輯看似 repo 內檔案，實際 symlink 指向外部敏感檔案；多款工具曾受影響，部分已修補。檔案路徑信任錯誤；AI 工具可把提示注入轉成越界寫入。寫入前 canonical path 驗證；拒絕 symlink／junction 越界；工具權限拆分；更新供應商修補。
ServiceNow CVE-2026-6875
TWCERT 8/31 二手整理		ServiceNow AI 平台；未驗證接收點（pre-auth sink）與沙箱。TWCERT 引用威脅情報稱可逃逸沙箱並 RCE，且自 7/19 有利用觀察；版本與部署型態需回查原廠。高價值業務工作流成為 pre-auth 入口；平台權限可能擴大資料影響。依原廠公告升級；外部入口 WAF／網路隔離；驗證 sandbox boundary 與最小服務身分。

共同攻擊模式

資產被低估測試、備援、公開評測服務或編碼工作區未納入同等威脅模型。
取得外部通道代理漏洞、刻意開放 Internet 或外部 relay 讓 agent 觸及真實服務。
輸入變執行資料集 loader、模板、README、symlink 或 pre-auth sink 把內容轉成檔案／程式碼動作。
身分擴張從 worker、平台或使用者工作區取得 token、檔案、服務目錄或雲端 metadata。
自動重試與協作多步驟規劃、重試、共享 cache／artifact 或多 agent 分工壓縮反應時間。
證據分散模型 transcript、工具、OS、網路與 IAM 記錄不一致，增加鑑識難度。
防禦重點：把「模型是否拒絕」降為其中一層；真正的邊界要在網路、執行器、身分與不可竄改觀測層實現。

控制與防禦架構

控制面最低實作要求驗證／偵測
Scope & approval每次 run 定義目標、允許動作、禁止網域與成本上限；高風險工具需人工核准；違規自動終止。策略命中事件；未授權目的地；停止延遲；人工批准與實際執行一致性。
Egress預設 deny；代理只允許必要 registry／API；解析 redirect、DNS rebinding、CONNECT、任意 URL fetch；記錄 agent identity。HTTP/DNS/TLS SNI 不一致；新目的地；高頻重試；代理被當作通用 relay。
Runtime sandbox一次性 VM／microVM；唯讀 rootfs；阻斷宿主 socket、特權、敏感掛載；seccomp／AppArmor／SELinux；每 run 清理。逃逸測試；跨 run 殘留；異常 syscall；工作區外檔案寫入；symlink canonical path。
資料處理器不可信 loader／模板／文件在無秘密、無 metadata、無生產網路的隔離 worker 執行；停用遠端程式碼與不必要 expression evaluation。惡意 dataset corpus；檔案 allowlist；模板語法測試；worker egress 與掛載檢查。
身分／秘密短 TTL workload identity；scope／audience／resource 綁定；禁止把長效 token 放環境變數；broker 按需發放，結束即撤銷。秘密讀取告警；token 來源／地理／workload 異常；權限圖漂移；撤銷演練。
共享記憶禁止用未授權 cache、artifact、dataset 當 message bus；必要時使用具身份、ACL、TTL、簽章和審計的正式 broker。跨任務 cache 可見性；匿名寫入；異常檔案格式；超額訊息與檔案交換。
證據完整性工具執行器、OS audit、DNS／HTTP flow、IAM、K8s audit 與 artifact digest 分開記錄至追加式儲存；事件串接簽章。序號缺口；hash chain 斷裂；來源時間偏移；transcript 與實際工具結果不一致。
AI 輔助鑑識可在隔離或本地部署模型，分析真實 payload；所有摘要保留原始證據鏈與人工覆核；記錄模型版本。分析 agent 誤判率；引用原始事件比例；重跑結果差異；外部 API 敏感資料外流。

落地優先序

0–7 天｜盤點出口列出所有 Agent runner、AI coding tool、dataset／RAG worker、套件代理與外部 relay；找出可接觸 Internet、秘密或內部 API 的工作負載。
0–7 天｜關閉高風險路徑封鎖 metadata route；輪替可能被 worker 讀取的 token；對 symlink 越界寫入、任意 URL fetch 與外部 template evaluation 做拒絕測試。
1–4 週｜重做 Agent 身分每次 run 使用獨立短效身份與工具 allowlist；將高風險命令與外部目標納入人工核准；建立全域 kill switch。
1–4 週｜集中不可改紀錄把 tool call、程序、網路、IAM、K8s 和檔案雜湊送往 Agent 無法修改的儲存；演練 transcript 與實際執行不一致。
持續｜紅隊與評估使用授權的 cyber range 測試 scope 越界、沙箱逃逸、憑證讀取、cache 協作和自動重試；每次測試先定義停機條件。
持續｜漏洞追蹤以 CISA KEV、NVD、TWCERT/CC、原廠公告與 SBOM 對照資產；將「已知遭利用」與單純高 CVSS 分開排程。

社群解法與技術 Repo 參考

以下是可用來做驗證、隔離、政策控管與執行期觀測的開源專案。它們不是本事件的官方修補，也不代表直接部署就能消除風險；建議先在授權的測試環境建立 proof-of-control，再評估整合。

用途社群專案可對應的控制Demo 建議
Agent prompt injection 測試AgentDojo動態環境、工具濫用與間接提示注入評估。建立含惡意工具輸出的測試集，量測任務完成率與越權率。
LLM 弱點掃描NVIDIA garak提示注入、資料洩漏、jailbreak、幻覺等探測。將 probe 版本、模型版本與防禦設定一併留存，避免只看單次分數。
沙箱隔離gVisor／Kata Containers降低不可信程式碼接觸宿主 kernel、檔案與其他工作負載的機會。驗證宿主 socket、metadata、敏感掛載、跨 sandbox 讀寫與逃逸告警。
政策與准入Open Policy Agent／Gatekeeper以 deny-by-default 管理工具、目的地、Kubernetes 資源與部署條件。把 Agent identity、工具名稱、資產標籤與風險等級納入 Rego 決策輸入。
執行期偵測Falco觀察 syscall、容器與 Kubernetes 事件，針對異常行為告警。建立「新外連＋秘密讀取＋shell 啟動＋跨 namespace」複合規則。
跨層觀測OpenTelemetry Collector集中收集 tool call、trace、log 與 metrics，串起 Agent 行為時間線。以 run_id、agent_id、tool_id、目的地與 artifact digest 做關聯欄位。
供應鏈簽章Sigstore Cosign驗證容器、模型、設定與其他 OCI artifact 的來源和完整性。部署前要求簽章／attestation，拒絕未簽或 digest 不符的 artifact。
威脅分類MITRE ATLAS data／OWASP GenAI Security把事件映射到 AI 特有的 TTP 與應用風險，協助建立偵測覆蓋表。每期報導保留 technique、證據、控制與尚未覆蓋的 gap。
使用提示：Repo 連結是技術參考入口，版本、威脅模型與授權條款需由工程團隊自行審查；任何測試只在明確授權的資產與隔離環境執行。

證據等級與限制

  • 高：台灣資安署、OpenAI、Anthropic、Hugging Face 的官方披露與後續說明。
  • 中：TWCERT/CC 月報所整理的供應商／威脅情報與媒體來源；可用來建立追蹤項目，仍需回查原廠公告和自身版本。
  • 統計限制：不同事件的日期、模型、測試條件和資料集不同；不可把測試行動數、真實攻擊動作或月報事件件數直接相加。
  • 工程限制：公開報告會刪節主機、憑證和指標；本報不補寫未公開 payload，也不把意圖、嘗試或概念驗證寫成已成功入侵。
