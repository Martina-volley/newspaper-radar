AI cybersecurity watch · 2026.10.08

韓國金融外洩確認；獨立鑑識首次把多 Agent 攻擊鏈連到實際資料外傳

主要觀察窗為 2026/10/05 18:33 至 10/08 18:33（台灣時間），並續追前一期事件。資料外洩本身發生於 9 月底；本期新增的是 10/06 韓國政府聯合應變與 10/07 CrowdStrike 對 ARTEX、LLM、session 與 memory 痕跡的技術串接。

決策／資安入門版72 小時＋前期事件續追事件、披露、歸屬分列
本期判定｜有重大新增披露，但不是 72 小時內才發生的新入侵。韓國官方確認多家金融機構近期發生個資外洩並展開跨部會處置；獨立威脅情報把攻擊基礎設施、ARTEX 設定、Claude Code session、memory 檔與韓國金融目標重疊起來。這支持「攻擊者使用 Agent 工具加速多目標入侵」，不支持「AI 完全自主、無人操作」或特定國家政府歸屬。

01本期焦點

本期最重要的變化，是 AI 參與證據從工具名稱痕跡升級為可交叉驗證的操作紀錄。 CrowdStrike 於 10/07 表示，在攻擊者控制的公開目錄中取得 ARTEX 設定、Claude Code session history 與 Claude memory；內容顯示 9 月底至 10 月初針對韓國金融機構的密集活動，並與公開報導的受害組織重疊。

韓國政府 10/06 已把事件視為金融與公共機構個資外洩危機，要求全面盤點、調查、客戶保護與跨金融業安全檢查。官方公告確認「資料外洩與應變」；AI 使用細節目前主要來自獨立鑑識，兩者不可混成同一信心水位。

實際活動多家韓國金融機構遭入侵或探測；銀行後續確認客戶資料外洩。新韓銀行官方設置外洩查詢與專線，韓國國家通訊社轉述銀行稱約 25,000 名客戶資料受影響。
2026/10/06
官方應變韓國政府召開跨部會會議，要求查清範圍與原因、擴大全金融業安全檢查、關閉閒置網站並加速刑事調查；金融主管機關另啟動一個月二次傷害特別應變。
2026/10/07
獨立披露CrowdStrike 公開 ARTEX、LLM session／memory 與攻擊基礎設施的鑑識，稱活動已造成資料外傳；受影響組織總數仍未完全確認。
2026/10/08 18:33
查核截止未見 CISA KEV／NVD 對此金融攻擊鏈建立直接漏洞條目，也未見台灣資安署或 TWCERT/CC 發布同事件新警訊。

03為什麼重要

  • 不是單純 PoC：銀行與政府已確認資料外洩和應變，獨立鑑識則補上 AI 工具如何參與的技術證據。
  • 邊緣系統成突破口：公開資訊指向貸款查詢、行動工作支援等周邊服務；核心銀行系統安全不代表外圍入口安全。
  • 多目標節奏被壓縮：Agent 能把資產盤點、弱點測試、路徑規劃與工具執行串成平行工作流，提高單一操作者的覆蓋率。
  • transcript 也是攻防面：session 與 memory 能協助鑑識，也可能洩露受害者、工具、金鑰或操作者線索；必須被當成敏感證據治理。

04Agent 行為痕跡

多 Agent 規劃

ARTEX 官方專案描述 planner、worker、共享待辦與資產圖；CrowdStrike 則在攻擊基礎設施看到 ARTEX 設定及多模型工作痕跡。這支持協調式自動化，但仍有操作者存在。

Session 與 memory

公開目錄暴露 coding session、設定與 memory 檔，顯示攻擊者把 Agent 記憶與逐次互動留在可被第三方取得的位置。攻擊者自己的 Agent 資料也會成為歸因與偵測來源。

多模型後端

研究方稱 ARTEX 以一個主要 LLM 後端運作，並搭配其他模型／coding agent。多模型並不等於無人自主；關鍵是誰設定目標、scope、credential 與最終行動。

05對企業的影響

  • 把貸款、合作夥伴、客服、員工行動入口與閒置網站納入核心金融系統同等級的資產盤點與 owner 管理。
  • 不要只封鎖單一 IP；對短時間跨多入口的相似探測、認證繞過、異常 API 列舉與資料匯出建立行為關聯。
  • 盤點企業內合法 pentest／coding Agent，集中保管 API key、transcript、memory、tool configuration 與目標 scope。
  • 資料外洩後，除通知外還要針對貸款、收入與聯絡資料被組合利用的精準詐騙強化交易驗證。

06我們應追蹤什麼

韓國官方鑑識受影響機構與人數、實際入口、資料類型、是否共用同一操作者，以及 ARTEX／LLM 使用的官方確認。
獨立研究驗證session／memory 時序能否和銀行 log、外傳紀錄、受害者通知對齊；目前不能只用工具字串做完整歸屬。
Zammad 10249010/06 的 Zammad 7.2.1 修補了多項重大弱點，但 release note 未明說修補 CVE-2026-102490；仍需等待明確映射。
OpenAI／Manus前期事件是否新增官方時間線、回歸測試與受害範圍；截至截止時間未見足以改變既有判定的一手更新。
台灣官方資安署／TWCERT/CC 是否針對 ARTEX、金融周邊入口或 Agent 工具濫用發布警訊；目前未見同事件公告。

073 句結論

  1. 韓國金融個資外洩是已確認事件；AI Agent 參與則由 10/07 獨立鑑識提供強技術證據，但官方最終歸屬仍在調查。
  2. 這更像「人類操作者以 ARTEX 與多模型提高攻擊節奏」而不是無人類參與的自主 AI 入侵。
  3. 企業現在最該做的是盤點周邊入口、關聯多目標高速行為、集中治理 Agent 的 credential／egress／memory／transcript，並把模型外證據送入 SIEM。
