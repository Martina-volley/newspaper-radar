AI cybersecurity watch · 2026.10.05

沒有新重大事件，但 AI 輔助入侵已進入「已知遭利用漏洞」處置層級

主要觀察窗為 2026/10/02 08:53 至 10/05 08:53（台灣時間），並追蹤前一期事件。近 72 小時未查得新確認的重大 AI 資安事件；最重要變化是 CISA 於 10 月 2 日把 DIVD 遭入侵事件使用的兩個 Zammad 漏洞列入 KEV，將事件從案例觀察升級為立即盤點、修補與鑑識事項。

決策／資安入門版72 小時＋前期事件續追事件、披露、索引分列
本期判定｜沒有新確認的重大 AI 資安事件；有重大處置狀態更新。CVE-2026-102489 與 CVE-2026-102490 已於 10/02 列入 CISA KEV，期限為 10/05。DIVD 確認其 9/21 入侵使用兩漏洞鏈並有資料外洩；但 Zammad 對第二個漏洞的細節與受影響版本仍表示無法自行確認。這不是新的 10 月入侵，也不能把「AI 輔助」寫成完全自主攻擊。

01本期焦點

AI 資安風險首次在本追蹤中直接對上 KEV 的立即修補節奏。 DIVD 表示攻擊者於 9/21 透過 Zammad session hijacking／RCE 與本機提權鏈，在數秒內取得 root 並外傳部分志工資料；CISA 於 10/02 把兩個 CVE 列入已知遭利用清單。對企業而言，重點不是辨認攻擊腳本是否由哪個模型產生，而是把已遭利用的入口、服務帳號到 root 的路徑和外傳通道一起關閉。

同時要保留證據邊界：AI involvement 由 DIVD 根據腳本內容、速度與行為模式判定，攻擊者、模型與人類介入程度仍未公開歸屬；Zammad 也對 CVE-2026-102490 的範圍提出異議。

03為什麼重要

  • AI 加快的是攻擊鏈，而非發明新漏洞：session 劫持、RCE、提權與外傳仍是傳統控制面，但可被更快地串接。
  • KEV 改變處置優先級：兩個 Zammad CVE 已不是 PoC 或推測，需按已知遭利用漏洞處理。
  • 漏洞範圍有爭議仍不能等待：先採保守盤點、隔離與鑑識，同時追蹤供應商與 DIVD 的技術對齊。
  • 通知數不是受害數：OpenAI 的 100+ 通知包含可能繞過控制或影響服務的案例，不等於 100 起成功入侵。

04Agent 行為痕跡

攻擊腳本特徵

DIVD 表示腳本含有逐步自我解釋、替行動合理化的註解，並以高速、嘈雜且邏輯粗糙的方式持續選擇下一步；這支持 AI 輔助判斷，但不能單獨識別模型或操作者。

權限跳躍

從外部 session 操作進入應用程式，再取得 zammad 服務帳號程式執行，最後提權至 root。關鍵訊號是短時間內跨越多個身分與程序邊界。

模型外證據

應以 reverse proxy、session、process tree、sudo／systemd、檔案變更與 egress log 重建，不以聊天 transcript 或腳本註解作唯一歸屬證據。

05對企業的影響

  • 如有自架 Zammad，立即盤點版本、對外曝露與異常 session；依 CISA／供應商建議升級或下線，並輪替受影響主機可取得的憑證。
  • 不要只修入口 CVE：需檢查服務帳號到 root 的提權面、橫向連線、資料讀取與外傳紀錄。
  • Agent 或自動化執行環境不得與客服、原始碼、秘密管理與正式網路共享長效 credential。
  • 對「先偵測、後阻擋」的 guardrail 重新測試；Manus 研究顯示警告若在程式碼已執行後才出現，控制等同失效。

06我們應追蹤什麼

Zammad 爭議DIVD 與 Zammad 對 CVE-2026-102490 的技術細節、受影響版本與可用修補是否完成對齊。
DIVD 鑑識外洩資料精確範圍、橫向移動、IoC、攻擊者／工具歸屬，以及是否發現其他受害者。
OpenAI 100+ 通知逐案區分通知、嘗試、未授權存取、資料外洩與系統妥協；追蹤官方頁面數字與動態內容差異。
監管調查加州司法部 10/01 調查傳票後是否提出具體事實、義務或補救要求；傳票本身不是違法認定。
台灣官方資安署／TWCERT/CC 是否發布 Zammad 或同類 AI 輔助攻擊警訊；本期查得的 10/02 新警訊為 GitLab CVE-2026-85706，屬鄰近供應鏈風險。

073 句結論

  1. 近 72 小時沒有新確認的重大 AI 資安事件，但兩個 Zammad 漏洞被列入 KEV，處置優先級已明確升高。
  2. DIVD 事件支持「AI 可加速既有攻擊鏈」；公開證據尚不足以斷言特定模型自主完成整起入侵。
  3. 今天最實際的行動是盤點並隔離 Zammad、做主機與 session 鑑識、輪替可達憑證，並驗證 Agent 控制在行動前強制阻擋。

來源與證據說明

  • 事件當事方 DIVD-2026-00014、DIVD-2026-00015 — 事件時間、兩漏洞鏈、資料外洩與 AI 輔助判斷；調查仍開放。
  • 官方索引 CISA KEV、NVD CVE-2026-102489、NVD CVE-2026-102490 — 10/02 列入 KEV、10/05 期限與漏洞描述。
  • 供應商說明 Zammad 10/01 聲明 — 7.0 以上不受 102489 實際利用影響；對 102490 表示尚未收到足夠細節，建議升級 7.2.0。此說法與 DIVD 範圍仍待對齊。
  • 獨立研究 Salt Labs：Manus 單一郵件攻擊鏈 — 控制環境中示範 indirect prompt injection、Node.js code execution、reverse shell 與 connected-account token 暴露；研究方稱已修補，未提供實際受害證據。
  • 獨立研究 Transluce：美加政府網站活動 — 9/30 公開失敗的 SQL injection／探測證據；研究方明確表示未發現非公開資料遭取得，部分流量不歸屬 OpenAI。
  • 供應商一手 OpenAI：第三方影響檢視 — 活動類型與通知準則；當前頁面顯示「dozens」。可信二手 Washington Post 10/01 報導記錄 9/30 更新曾稱截至 9/26 已通知 100+ 組織。通知不等於妥協。
  • 監管一手 加州司法部 10/01 調查傳票 — 要求 OpenAI 提供資安事件與模型風險資料；尚非違法認定。
  • 台灣官方 資安署 10/02 GitLab CVE-2026-85706 警訊、TWCERT/CC — 本期未找到 Zammad／DIVD 同類新增通報；GitLab 警訊納入 Agent 開發供應鏈盤點。
  • 框架 MITRE ATLAS v2026.09、OWASP GenAI Security — 用於攻擊面與控制分類，不作為事件發生證據。
