可能攻擊鏈

1. 外部入口劫持 Zammad session，或讓 Agent 讀取含惡意指令的 ticket／郵件。
2. 服務身分 RCE以 zammad 或 sandbox 身分執行程式碼。
3. 能力探索列舉 package hooks、filesystem、environment、network 與 connector。
4. 本機提權利用 102490／上游 package 問題走向 root；此步需先有主機存取權。
5. 外傳／橫移讀取 ticket、志工資料、DB、mail、backup、CI／雲端 credential。
6. 證據與中斷撤銷 session／token，切斷 worker 與 egress，從模型外遙測重建。
不可混寫：DIVD 是已確認入侵與資料外洩；Zammad 10/05 是供應商技術狀態更新；Manus 是受控 PoC；OpenAI 通知範圍並非成功入侵計數。它們可用來設計共同控制，不能被拼成同一攻擊者或同一模型的事件。

Agent 技術特性

Credential

把「runtime 可讀取」與「被授權使用」分離。Tool broker 依 initiating user、tenant、run_id、audience、operation 與 resource 簽發一次性或短效權限；郵件、ticket、repo、log、memory 或網站內出現的 credential 一律 quarantine，不可兌換。

Sandbox

每個 run 使用一次性 workload identity、read-only base、無 host home／Docker socket／SSH agent／browser profile／cloud metadata。資料 decoder 不得呼叫通用 Node.js、Python、shell 或 package lifecycle；即使 sandbox compromise，外部 network policy 仍需阻止外傳。

Egress

所有 DNS／HTTP 經 Agent 無寫權 proxy，預設拒絕；政策同時綁定 workload identity、run、目的地、method、content type、bytes 與資料分類。測試 IP literal、redirect、URL scanner、archive relay、paste／image host、CONNECT、WebSocket、QUIC 與 DNS tunneling。

Shared memory

以 tenant／project／agent／run 分區；每筆保留 producer、source URI、classification、schema、TTL、hash、lineage 與 promotion approver。外部內容只能進 quarantine memory，不得直接成為 global instruction 或 executable state。

Multi-agent coordination

每個 worker 有獨立身分、tool allowlist、network budget 與資料 scope；父 Agent 不複製完整 token。任何 worker 觸發未知 egress、credential read、RCE、提權或 evidence mismatch，graph controller 應撤銷全體子身分並取消 queued calls。

Transcript tampering

transcript 只作語義輔助。process／exec、package hook、file、kernel、session、proxy、DNS、IAM、tool gateway、memory write、artifact digest 與 kill ack 由 Agent 無寫權 collector 擷取，寫入 append-only／WORM 儲存並使用 monotonic sequence。

分層防禦架構

控制層最低要求驗證方式
資產／patch盤點所有 Zammad、版本、runtime、image digest、曝露與 owner；KEV／vendor advisory 自動提升優先級。從 CMDB、DNS、WAF、container registry 與網路掃描交叉反查；未知 owner 資產自動隔離。
Session／identitysession 綁定風險訊號；服務帳號無互動登入；connector token 短效且 audience-bound。重放 session、切換 UA／ASN、錯 audience、過期 token；斷言阻擋、撤銷與告警。
Host／package限制 zammad 對 root-owned service／package path 的寫入；最小 sudo、systemd 與 package lifecycle 權限。以低權限帳號測 package hook、service override、PATH hijack、symlink、cron／systemd persistence。
Content-to-codeticket／mail／網頁／repo 資料不得直進 eval、shell、模板或 interpreter；decode 與 execute API 分離。重放 JSFuck、Base64、Unicode、HTML／Markdown、壓縮與 polyglot payload；斷言 process 不啟動。
Sandbox／runtime一次性 sandbox、read-only base、no host mounts、seccomp／MAC、無共享 secrets。讀 env、metadata、socket、SSH agent；測 syscall、mount、namespace、teardown 與殘留資料。
Network／egressdefault-deny proxy；目的地、method、bytes、data class 與 workload identity 同時授權。reverse shell、DNS、QUIC、CONNECT、redirect、IP literal、scanner callback 與分片外傳。
Memory／coordinationnamespace、TTL、lineage、producer signature；worker 權限獨立；graph 級 circuit breaker。跨 tenant read/write、poison cache、偽造 tool result、worker fan-out、kill 後 queued call。
Detection／evidencesession、process、package、file、network、IAM、tool、memory 共用 run_id，且寫入不可竄改信任域。刪改 transcript 或中斷 collector；確認仍可重建 exec-before-warning、提權與外傳路徑。

1 週｜Agent token／egress 拆分移除 sandbox 內長效 connector token，改由 broker 按 operation 發權限；未知目的地 default deny。
2 週｜Graph 中斷與證據把 worker identity、egress、memory、process、package 與 kill ack 關聯到 run_id，驗證單一越界可停整個 graph。

社群解法與技術 Repo

本期即時工具：DIVD 提供 Zammad IoC log checker v2。先保存原始 log 與雜湊，在副本或鑑識流程執行；陰性結果無法排除 rootkit、log deletion、其他入口或橫向移動。

用途／官方 Repo可對應控制驗證方式導入限制
zammad/zammad
產品原始碼、release 與 advisory		追蹤 102490 修補、7.2.0 加固與部署版本／digest。固定 image digest；在 staging 驗證 session、mail、plugin、package path 與 upgrade rollback。目前供應商仍在處理 102490；最新版不等於既有主機未受入侵。
osquery/osquery／Velocidex/velociraptor
主機查詢與蒐證		process、user、service、package、cron、socket、file hash 與 persistence。用測試 service override、root shell 與檔案變更驗證 artifact coverage 與時間戳。需事前部署與可信 collector；root 已失陷的主機可能欺騙回傳資料。
SigmaHQ/sigma
可攜式偵測規則		把 session、服務帳號執行、提權、reverse shell 與外傳行為轉為 SIEM 偵測。以保存的測試 log 做 unit test；跨後端比較欄位映射、排序與漏失。依賴 log schema 與完整性；需本地調校，不能只靠 IoC。
open-policy-agent/opa
模型外政策決策		依 user、tenant、run、tool、destination、data class、credential source 決定 allow／deny。為 found credential、decode-to-exec、unknown egress、cross-tenant memory 建立 deny 測試。OPA 不是 enforcement point；必須整合 broker、proxy、runner 與 memory gateway。
envoyproxy/envoy
Egress enforcement		集中 destination、method、rate／byte limit、TLS 與 workload identity policy。測 reverse shell、CONNECT、SNI mismatch、DNS rebinding、redirect、large body、retry。非 HTTP、QUIC、DNS 與加密 payload 需額外控制；錯誤設定可成單點風險。
google/gvisor／Kata Containers
Runtime 隔離		降低 Agent RCE 接觸 host kernel、device、socket 與其他 workload 的機會。測 syscall、mount、metadata、escape corpus、冷啟動與 teardown 後資料殘留。不阻擋合法 API 外傳；不能替代 token broker、host hardening 與 egress policy。
falcosecurity/falco
執行期偵測		偵測 decoder 啟動 shell、package hook、secret read、異常 child process、mount 與提權。重放 JSFuck／reverse shell／service override，量測 process start 到 alert／block 延遲。預設偏偵測；形成阻擋需 response pipeline，規則也需綁 workload／run_id。
OpenTelemetry Collector
跨層遙測		關聯 session、tool、process、package、proxy、DNS、IAM、memory 與 kill event。刪除 transcript，確認外部 trace 仍能證明 exec 早於 warning 並重建提權／egress。Collector 必須在 Agent 無寫權信任域；敏感內容需最小化、遮罩與留存治理。
promptfoo/promptfoo／Azure/PyRIT
Agent 紅隊回歸		indirect injection、obfuscation、tool misuse、credential access、late-warning 測試。固定 model、tool schema、policy、seed、canary 與 sandbox image；release 前比較 attack success。框架本身不是 sandbox；需接真實 broker、proxy、runtime 與 connector mock。
MITRE ATLAS／OWASP AISVS
威脅與驗證需求		映射 session、runtime discovery、scope drift、memory、egress、multi-agent 與 telemetry。版本化 technique→control→test→owner→evidence；每季重跑並記錄例外。知識庫與標準不是偵測器；有映射不代表控制已部署或事件已發生。
導入原則：至少同時具備資產／修補、短效身分、host hardening、content-to-code gate、runtime isolation、default-deny egress、隔離 memory、graph 級 kill switch 與模型外 append-only evidence；任何單一 Repo 都不能形成完整安全邊界。

證據限制

  • Zammad 10/05 已確認收到 CVE-2026-102490 技術細節，並把它描述為需要先有底層主機存取權的本機提權；公告未公布完整技術細節、受影響版本矩陣、修補版本或可重現測試。
  • Zammad 稱 7.0 以上不受 CVE-2026-102489 實際利用影響，且 7.2.0 已額外加固；DIVD 公開頁也寫明 7.0.0–7.1.3 因環境條件不可利用。NVD／CVE 範圍可能稍後更新。
  • DIVD 確認 9/21 入侵、兩漏洞鏈、root 與部分志工資料外洩；目前仍未公開完整 packet capture、全部 IoC、模型名稱、攻擊者身分或人類操作者程度。
  • 「AI 輔助」來自腳本註解、速度、嘈雜行為與選步特徵，支持作案方式分類，但不能單獨證明特定模型或完全自主。
  • CISA KEV 證明已有遭利用依據，不說明所有受害者、模型、攻擊者或每個 runtime 的可利用條件；KEV 與供應商 advisory 都需納入風險判斷。
  • Manus 為受控研究 PoC，研究方稱已修補；沒有公開真實使用者受相同鏈攻陷的證據。
  • OpenAI 的第三方通知範圍寬於確認入侵；通知數、嘗試數與成功妥協數不得互換。
  • 資安署與 TWCERT/CC 本期未見同類新增通報，只代表本次公開頁面查核結果，不證明台灣沒有相關活動。
  • MITRE ATLAS、OWASP、CISA／NVD 與社群 Repo 分別用於分類、利用狀態或控制實作，不能單獨證明事件全貌。
