攻擊面與技術

Palo Alto 公告明確指向 PAN-OS／Panorama 管理 web UI 與 XML API，並稱 GlobalProtect portal／gateway 本身不受此項影響。Dream 的復原產物顯示批次版本指紋、PHP 記憶體錯誤利用、核心提權、root webshell、反向 SSH 隧道與 LDAP 憑證解密。高風險條件是管理介面對公網開放；先按分支核對公告修補版。

可能攻擊鏈

  1. 公開管理介面被盤點、版本指紋比對。
  2. 符合條件者遭 PHP2Shell 遠端執行，再接核心提權取得 root；Dream 稱 24 台邊界設備成功。
  3. 在其中一目標，取配置、建反向隧道，再入侵內部管理伺服器，使總數達 25。
  4. 解出 LDAP 服務帳密、列舉 AD；密碼噴灑、後門帳號及 SAML 金鑰結果未知。

這是 Dream 對同一事件的復原鏈，獲 Unit 42 驗證工具與結果；不是所有受害設備都已證明完成橫移。

Agent 技術特性

沒有可公開核對的 Agent 任務指令、工具呼叫、跨回合記憶或多 Agent 協調 transcript。Dream 所見的 Claude Code 安裝與 aiscan／LLM 設定僅是「可能 AI 輔助」線索；腳本風格不是因果證明。研究者用自家 autonomous research 產品發現產物，也不等於攻擊者使用同一系統。

六個控制面：credential／sandbox／egress／shared memory／multi-agent coordination／transcript tampering

控制面本案證據與界線驗證動作
credentialLDAP 服務帳密遭解出；其他憑證暴露待核輪替相關設備／LDAP 憑證，追查解密後使用
sandbox無 Agent sandbox 逃逸證據；PAN-OS 系統提權是另一回事隔離本機 Agent 工具與網路設備管理域
egressDream 指出反向 SSH 隧道核對管理設備出站連線、DNS 與代理紀錄
shared memory無跨 Agent 記憶遭操控證據盤點共享工作區、記憶儲存 ACL 與稽核
multi-agent coordination未證實攻擊者有多 Agent 分工保留編排器 task／tool call 時序
transcript tampering無 transcript 修改證據將 prompt、工具回應、審批及系統事件寫入獨立不可改稽核

分層防禦架構

  1. 暴露層：將管理面移出公網，只准可信內部位址或跳板。
  2. 修補層：按 供應商分支公告升級；不能用單一版本號套所有分支。
  3. 偵測層：用 Unit 42 的獵捕指引檢查 PHP worker 異常命令、webshell、隧道、配置讀取與 LDAP 活動。
  4. 身分層：限制服務帳號權限、輪替疑似已解出的帳密與裝置私鑰。
  5. Agent 層：套件鎖版／簽章、MCP 工具權限與隔離稽核；本案無 Agent 執行因果證據，屬預防控制。

證據限制

  • Dream 的 25 是伺服器數，非組織數；台灣設備身分未公開。19,000 個搜尋候選與 240 個嘗試不是成功數。
  • Unit 42 10/25 撤回的歐洲政府案件與 10/29 確認的 Dream 案不同；不得以新證據倒填舊案。
  • AI 安裝／配置不證明 AI 撰寫 exploit、成功協調或自主入侵。AD 後門、密碼噴灑、SAML 私鑰成功與否仍未確認。
  • GitHub 惡意套件公告是主機應變警訊，沒有公開下載／受害數。
