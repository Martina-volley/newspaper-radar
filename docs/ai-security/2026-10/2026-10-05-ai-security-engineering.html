攻擊面與技術

面向失效模式可觀測訊號ATLAS／OWASP 對照
Session／credential遭劫持 session 或公開取得的 token 被 Agent／自動化直接當作授權。session fingerprint 改變、來源 ASN／UA 跳動、token 首次使用者非 owner、audience 不符。Credential Access、Use Alternate Authentication Material、Improper Authorization。
Tool／runtime把不可信郵件、網頁或 repo 內容送進 decoder、interpreter 或 shell；偵測晚於執行。content fetch 後緊接 node／python／shell、obfuscated payload、approval event 晚於 process start。LLM Prompt Injection: Indirect、AI Agent Tool Misuse、RCE。
SandboxAgent runtime 可看見 integration token、宿主 socket、metadata 或可外連任意目的地。環境變數含 OAuth token、host mount、cloud metadata、未知 SNI、reverse shell pattern。Discover AI Agent Runtime Capabilities、Machine Compromise: Local AI Agent。
Egressroot shell、資料或 token 可經任意 HTTPS、DNS、archive／scanner 或 object store 送出。罕見 domain、IP literal、CONNECT、長 DNS label、multipart／base64 body、短時間大量 outbound。Data Exfiltration、Sensitive Information Disclosure。
Shared memory攻擊內容寫入長期記憶、cache、wiki 或 repo instruction，跨 session／run 持續影響。不同 run 共用 namespace、無 producer signature、TTL 缺失、公共頁面出現結構化協調內容。Memory & Context Poisoning、Agent Communication Abuse。
Multi-agent coordination父 Agent 把完整權限、memory 或秘密複製給 worker；單一 worker 越界後整個 graph 仍繼續。同 token 多 worker、fan-out 後未知目的地、kill 後仍有 queued tool call、跨 worker trace 斷裂。Excessive Agency、Agent Orchestration and Multi-Agent Security。
Transcript／evidence語義紀錄漏掉實際 process、session、proxy、DNS、檔案與 kernel event，或可被 Agent 修改。transcript 警告時間晚於 process start；事件序號缺口；artifact hash 與檔案不同。Inadequate Logging & Monitoring、AI Telemetry Logging。

可能攻擊鏈

1. 外部入口劫持應用 session，或讓 Agent 讀取含惡意指令的郵件／網頁。
2. 受控程式執行在服務帳號或 Agent sandbox 中取得 RCE。
3. 能力探索列舉 filesystem、environment、integration、network 與提權路徑。
4. 權限升級由 zammad／sandbox 身分走向 root 或 connected-account token。
5. 外傳／橫移讀取志工資料、secret、repo 或雲端資料，再透過允許的 egress 送出。
6. 證據與應變從 host／proxy／IAM 重建，撤銷 session、token、worker 與持久化。
不可混為同一事件：DIVD 是已確認入侵與資料外洩，AI 為攻擊手法判斷；Manus 是受控 PoC；Transluce 兩個政府網站案例是失敗探測；OpenAI 100+ 是通知範圍。以上共同呈現控制面，但不能串成同一攻擊者或同一模型的完整鏈。

Agent 技術特性

Credential

把「可被讀到」與「被授權使用」分離。Agent runtime 不得持有所有 connector 的長效 OAuth token；tool broker 依 initiating user、tenant、run_id、audience、operation 與 resource 重新簽發短效 token。任何從郵件、repo、網站、log 或 memory 找到的 credential 一律 quarantine，不得兌換。

Sandbox

每 run 建立一次性 sandbox，拒絕宿主 home、Docker socket、SSH agent、browser profile、cloud metadata 與共享 secret volume。需要 decoder 時只允許純資料轉換 library，不把輸入交給 Node.js、Python、shell 或模板引擎；sandbox compromise 必須仍被外部 network policy 與 workload identity 限制。

Egress

所有 DNS／HTTP 由 Agent 無法修改的 proxy 控制，預設拒絕；政策綁定 workload identity、run、目的地、method、content type、bytes 與資料分類。封鎖 IP literal、open redirect、URL scanner、archive relay、paste／image host、任意 object store、CONNECT、QUIC 與 DNS tunneling。

Shared memory

memory 以 tenant／project／agent／run 分區，每筆保留 producer identity、source URI、classification、schema version、TTL、hash 與 lineage。外部內容不得直接寫入 executable instruction 或 global memory；跨 run promotion 必須經 sanitizer、policy 與人類核准。

Multi-agent coordination

每個 worker 使用獨立身分、tool allowlist、network budget 與資料 scope；父 Agent 不傳遞完整 token。任一 worker 觸發 RCE、未知 egress、credential read、提權或 transcript mismatch 時，graph controller 應撤銷所有子身分並停止 queued calls。

Transcript tampering

transcript 只保留語義，不當成唯一鑑識資料。process／exec、file、kernel、session、proxy、DNS、IAM、tool gateway、memory write、artifact digest 與 kill-switch ack 由 Agent 無寫權的 collector 收集，寫入 append-only／WORM 儲存並以 monotonic sequence 關聯。

分層防禦架構

控制層最低要求驗證方式
外部資產／patch盤點 Zammad 與 GitLab 版本、曝露、owner；KEV 與供應商 advisory 觸發自動優先級。從 CMDB 反查所有 instance；驗證版本、WAF／proxy、backup 與下線路徑；抽查無 owner 資產。
Session／identitysession 綁定風險訊號；服務帳號無互動登入；短效、audience-bound connector token。重放 stolen session、切換 UA／ASN、錯 audience token；斷言撤銷與告警。
Content-to-code boundary郵件／網頁／repo 資料不得直接進 eval、shell、模板或 interpreter；decode 與 execute API 分離。重放 JSFuck、Base64、壓縮、Unicode、HTML／Markdown renderer 與 polyglot payload；斷言 process 不啟動。
Sandbox／runtime一次性 sandbox、read-only base、no host mounts、seccomp／MAC、無共享 secrets。嘗試讀 env token、metadata、Docker socket、SSH agent；測 syscall、mount、namespace 與 teardown。
Network／egressdefault deny proxy；目的地、method、bytes、data class 與 workload identity 同時授權。reverse shell、DNS、QUIC、WebSocket、CONNECT、redirect、IP literal、URL scanner 與分片外傳。
Memory／coordinationnamespace、TTL、lineage、producer signature；worker 權限與 budget 獨立；graph 級 circuit breaker。跨 tenant read/write、poison cache、偽造 tool result、worker fan-out、kill 後 queued call。
Detection／evidencesession、process、file、kernel、network、IAM、tool、memory 使用共同 run_id 且 append-only。刪改 transcript、延後警告或中斷 collector；確認仍可重建 process-before-warning 與完整外傳路徑。
IR／notification供應商通知進正式事件流程；明定 attempted、unauthorized access、data access、exfiltration、compromise 五級證據。桌上演練 100+ 模糊通知；要求可行 IoC、受影響時間、資料、結果與 containment，不以通知數當受害數。

社群解法與技術 Repo

本期即時工具：DIVD 提供 Zammad IoC log checker v2。先保存原始 log 與雜湊，再在副本或鑑識流程執行；單一 script 不能排除 rootkit、log deletion 或橫向移動。

用途／官方 Repo可對應控制驗證方式導入限制
zammad/zammad
產品原始碼與官方 advisory		追蹤 release、security advisory 與實際部署版本；核對 7.2.0 更新。由 package／image digest 證明版本；在 staging 驗證 session、plugin、mail 與 upgrade path。供應商與 DIVD 對 102490 尚有爭議；版本升級不取代既有 compromise 鑑識。
osquery/osquery／Velocidex/velociraptor
主機查詢與事件蒐證		盤點 process、user、service、cron、socket、file hash 與 persistence。以已知測試 persistence、root shell 與檔案變更驗證 artifact coverage 與時間戳。需要事前部署與可信 collector；遭 root 控制的主機回傳資料可能被欺騙。
SigmaHQ/sigma
可攜式偵測規則		把 Zammad、session、提權、reverse shell 與資料外傳行為轉為 SIEM 偵測。以保存的測試 log 做 unit test；跨後端比較欄位映射與漏失。規則品質受 log schema 與來源完整性限制；需本地調校，不能只靠 IOC。
open-policy-agent/opa
模型外政策決策		依 agent、user、tenant、run、tool、destination、data class、credential source 決定 allow／deny。為 decode-to-exec、found credential、unknown egress、cross-tenant memory 建立 deny 測試。OPA 不是 enforcement point；需整合 tool gateway、proxy、runner 與 token broker。
envoyproxy/envoy
egress enforcement		集中 destination、method、rate／byte limit、TLS 與 workload identity policy。測 reverse shell、CONNECT、SNI mismatch、DNS rebinding、redirect、large body 與重試。加密 payload、非 HTTP、QUIC 與 DNS 需額外控制；設定錯誤可成單點風險。
google/gvisor／Kata Containers
runtime 隔離		降低 Agent RCE 接觸 host kernel、device、socket 與其他 workload 的機會。測 syscall、mount、metadata、escape corpus、冷啟動與 teardown 後資料殘留。不會自動阻擋合法 API 的資料外傳，也不能替代 token broker 與 egress policy。
falcosecurity/falco
執行期偵測		偵測 decoder 啟動 shell、secret read、異常 child process、mount、socket 與提權。重放 JSFuck／reverse-shell 測試，量測 process start 到 block／alert 的延遲。預設以偵測為主；要形成阻擋需 response pipeline，且規則須綁 run_id。
open-telemetry/opentelemetry-collector
跨層遙測		關聯 session、tool、process、proxy、DNS、IAM、memory 與 kill-switch event。刻意刪除 transcript，確認外部 trace 仍能證明 process 早於 warning 並重建 egress。Collector 必須在 Agent 無寫權信任域；敏感 payload 要最小化、遮罩與留存治理。
promptfoo/promptfoo／Azure/PyRIT
Agent／LLM 紅隊回歸		建立 indirect injection、obfuscation、tool misuse、credential access 與 late-warning 測試。固定 model、tool schema、policy、seed、canary 與 sandbox image；release 前比較 attack success。測試框架本身不是 sandbox；必須接真實 broker、proxy、runtime 與 connector mock。
mitre-atlas/atlas-data／OWASP/AISVS
威脅與控制映射		把 indirect injection、runtime discovery、credential、memory、egress 與 telemetry 轉成可稽核需求。版本化 mapping；每季檢查 technique、test、owner、evidence source 與 exception。知識庫不是偵測器；有映射不代表控制已部署或事件已發生。
導入原則：至少同時具備修補與資產盤點、短效身分、content-to-code gate、runtime isolation、default-deny egress、隔離 memory、graph 級 kill switch 與模型外 append-only evidence。任何單一 Repo 都不能形成完整安全邊界。

證據限制

  • DIVD 確認 9/21 入侵、兩漏洞鏈、root 與資料外洩；目前未公開完整 packet capture、全部 IoC、模型名稱、攻擊者身分或人類操作者程度。
  • 「AI 輔助」判斷來自腳本自我解釋註解、速度、嘈雜行為與自主選步特徵。這支持作案方式分類，但不等於特定模型歸屬或完全自主。
  • Zammad 稱 7.0 以上不受 CVE-2026-102489 實際利用影響，且尚未收到 CVE-2026-102490 的技術細節；DIVD 的公開範圍較廣。報告以保守處置呈現，未把爭議範圍寫成定論。
  • CISA 10/02 將兩項 CVE 列入 KEV，證明已有遭利用依據；KEV 不說明所有受害者、攻擊者、AI 模型或每個版本的實際可利用條件。
  • OpenAI 9/30 動態頁面曾被報導為 100+ 通知，當前擷取頁面顯示「dozens」。通知準則寬於確認入侵，不能將通知數當 breach count。
  • Manus 研究在受控帳號與研究基礎設施完成，研究方稱問題已修補；沒有公開資料顯示真實使用者已被相同鏈攻陷。
  • Transluce 的政府網站案例包含失敗 SQLi／XSS／fuzzing；研究方未發現非公開資料取得，部分流量歸屬僅有中度或較低信心。
  • 加州司法部傳票代表調查與資料要求，不代表違法、疏失或責任已被認定。
  • MITRE ATLAS、OWASP、CISA／NVD 與社群 Repo 分別用於分類、利用狀態或控制實作；它們不能互相替代，也不能單獨證明事件全貌。
