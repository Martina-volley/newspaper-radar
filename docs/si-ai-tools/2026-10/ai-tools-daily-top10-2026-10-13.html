Meta Muse Wonder 系列

Meta 於 10/12 推出 Muse Wonder 與 Muse Wonder Full，主打跨對話記憶、遇到困難時持續嘗試，以及重要操作前先詢問；Muse Wonder 已可透過 Meta Model API 與 Muse Code 使用，Full 版提供給 Muse Code 訂閱者。這是新一代代理模型的正式上線訊號，但「最強」等效能描述屬 Meta 自述，完整安全評估報告尚未公布。建議用多步任務測記憶是否取用正確、失敗後能否復原，以及送出或修改等重要動作是否確實停下來確認。

Microsoft-Decision-1

Microsoft 於 10/9 發布決策評分模型，可對固定選項輸出機率分數，供分類、路由、排序或判斷代理下一步使用，已可透過 Microsoft Foundry 與 OpenRouter 呼叫。Microsoft 公布的速度與準確率來自自家 36 項基準測試；這期追蹤它，是因它把代理流程中的「判斷」拆成結構化元件。用自有標註集驗證機率校準、選項重排後的一致性與錯誤升級人工覆核的門檻。

03

Microsoft Research StudentSim

Microsoft Research 於 10/12 介紹 StudentSim，以去識別化學習紀錄建立個別學生模擬器，供研究者在開發階段快速測試 AI 家教回饋；研究涵蓋西洋棋、英文寫作與數學。官方明確說明它是研究系統，尚非產品或教室部署方案，也不能取代真人學習者測試。可先檢查模擬反應是否能重現不同學生的回答與受提示後的變化，再以真人研究確認教學成效。

Anthropic Claude 蒸餾防護

Anthropic 於 10/12 說明如何偵測並降低大量擷取 Claude 推理資料的蒸餾行為，包含摘要推理內容、辨識索取隱藏推理的請求，以及處理假帳號網路。Anthropic 表示初步資料顯示被蒐集的資料量減少約 90% 至 99%；這是公司自述，且部分防護要求合法整合方調整串接方式。若使用相關 API，應確認新限制是否影響正常工作流，並觀察拒絕率及誤判。

代理需要把「做事」與「做決定」拆開驗證

Meta Muse Wonder 系列、Microsoft-Decision-1

Muse Wonder 主打跨步驟完成任務，Decision-1 則為固定選項提供可供程式採用的判斷分數，顯示代理能力正從單一模型延伸到可控的決策節點。

驗證重點比較多步任務完成率、關鍵動作前的停等確認，以及決策分數對應的實際正確率。

開發期評估增加模型化回饋

Microsoft-Decision-1、Microsoft Research StudentSim

Decision-1 以分數協助檢查輸出或代理行動，StudentSim 則模擬學生對教學提示的反應；兩者都讓迭代更快，但回饋訊號仍須由真實結果校正。

驗證重點以保留資料或真人測試檢查校準度，避免把模擬器分數直接當成真實成效。

模型能力升級也推高資料保護要求

Meta Muse Wonder 系列、Anthropic Claude 蒸餾防護

Meta 把新模型定位為能持續處理個人與專業任務，Anthropic 則加強阻止模型能力被大量擷取，代理產品的安全與資料防護開始同時面對使用端和供應端。

驗證重點查閱完整安全報告與 API 使用規則，並測試隱私、拒絕行為、資料輸出及合法流量誤判。
