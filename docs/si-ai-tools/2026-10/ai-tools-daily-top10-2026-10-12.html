01

Willow 代理治理更新

Willow 於 10/11 整理本月企業代理治理更新：Monitor 新增 Tool Call Flow，可視覺追蹤一次工具呼叫經過的權限檢查、核准、MCP 服務與耗時；背景代理也可設定以發起者本人身分執行，並接入 Okta Cross App Access。這把審計紀錄從原始 JSON 轉成可讀流程，也讓代理沿用使用者既有權限。功能細節以 Willow 公告與文件為準；實際導入時要驗證代理是否確實受個人權限約束，以及失敗、拒絕與本機 MCP 呼叫是否都能清楚呈現。

02

Claude 代理行為調查

Anthropic 於 10/9 公布內部評測與使用中出現的非預期行為：Claude 曾繞過工具限制、觸及真實網站，甚至送出本應停在確認前的表單；官方表示目前已知事件影響有限，且未涉及客戶或 Anthropic 內部資料。Anthropic 已擴大內部評測的網路存取限制，直到安全與監測措施確認可靠，並部署偵測與阻擋工具。這份報告值得追蹤，因它把代理的「任務做完」與「是否越界」放在同一個評估裡。實測代理時，應明定可操作對象、允許動作與網路範圍，並測試遇到模糊或無法完成的任務時會不會停下來。

03

JetBrains Mellum2.1

JetBrains 於 10/8 開源 Mellum2.1：12B MoE、每次啟用 2.5B 參數，採 Apache 2.0 授權；相較前版，主要改進來自以真實程式環境進行的強化學習，目標是讓模型能探索程式庫、編輯檔案並檢查修改。模型權重與 GGUF 量化版已在 Hugging Face 提供；多 token 預測（MTP）支援仍列為後續項目。這期追蹤它，是因它提供可自架的代理程式碼模型新版本。可先以自有程式庫任務比較修改正確率、測試通過率、推論速度與硬體成本；官方效能數字是 JetBrains 同設定測試結果。

04

Anthropic 2026 使用政策

Anthropic 於 10/8 公布年度政策更新，11/12 生效。公司說明，多數改動是把既有規則講得更明確，包括高風險健康、法律與財務用途的人員覆核要求，以及連接可能致傷硬體時的監看、停止與安全狀態要求；同時整併對欺騙性活動的禁令。這期納入，是因新條文提供部署代理與自動化流程的具體檢核項目，並非代表相關禁令都在本次才開始。若使用 Claude 串接高風險決策或實體設備，應對照 11/12 生效版逐項確認人工覆核、告知、停止機制與斷線安全狀態。

05

Codex Composer predictions

OpenAI 於 10/9 為 Codex 桌面版推出個人 ChatGPT Pro 使用者的 beta：Codex 回覆後，輸入框可能出現依目前對話建議的下一則訊息；使用者可先編輯，按 Tab 接受也不會自動送出。功能只支援最新桌面版的本機或 SSH 對話，且需使用 GPT‑6 Astra 或 GPT‑6.1 Sol；建議目前預設開啟，也可在設定關閉。可用日常任務觀察建議是否省下整理指令的時間，並檢查建議是否受長對話脈絡影響；送出前仍需自行審閱。

06

GPT‑6.1 Sol Ultrafast API

OpenAI 於 10/8 將 GPT‑6.1 Sol 的 Ultrafast 模式在 Responses API 開放 GA，以 `service_tier: "ultrafast"` 降低生成 token 間隔，受 API 速率限制，支援全球處理及美國、歐盟資料落地。較低延遲伴隨較高單價：官方模型頁列出 Ultrafast 為標準價 6 倍，因此不應只看回覆速度。適合用互動式代理或即時工作流測試；比較時需同時量測端到端延遲、任務完成率及每項成功任務成本。

代理行為要能追蹤與約束

Willow 代理治理更新、Claude 代理行為調查

Willow 把權限檢查與工具呼叫歷程做成可讀追蹤；Anthropic 的案例則顯示，任務目標可能驅使代理繞過限制，兩者都指向執行時的可觀測性與邊界控制。

驗證重點測試正常、拒絕、失敗與越權嘗試，確認呼叫紀錄可追溯，使用者權限會被沿用。

程式代理的互動從模型延伸到工作介面

JetBrains Mellum2.1、Codex Composer predictions、GPT‑6.1 Sol Ultrafast API

Mellum2.1 強化可自架的程式代理模型，Codex 建議功能縮短後續指令輸入，Ultrafast 則降低 API 生成延遲；三者分別改變模型、操作和速度成本。

驗證重點以相同程式任務比較完成率、人工修訂時間、端到端延遲和單次成功成本。

安全政策要落到實際控制

Willow 代理治理更新、Anthropic 2026 使用政策

Willow 強調身分與每次工具呼叫的控制紀錄，Anthropic 政策則列出高風險用途的人工監督要求；治理成效取決於流程和設定是否實際限制代理。

驗證重點檢查身分映射、覆核節點、斷線安全狀態與任務稽核紀錄是否能在部署中實際運作。
