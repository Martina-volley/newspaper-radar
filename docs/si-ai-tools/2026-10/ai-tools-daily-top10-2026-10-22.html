OpenAI 模型與 Codex 將進入 Google Cloud

OpenAI 與 Google Cloud 於 10/21 宣布合作，規劃把 OpenAI 模型和 Codex 工作流程放進 Google Cloud Model Garden，並可透過 Google Cloud Marketplace 採購；OpenAI 模型也預計進入 Google Antigravity 與 Gemini Agent。一般供應預計數週後開始，目前仍是合作公告，尚非已開放服務；OpenAI 也表示 Microsoft 仍是其主要雲端夥伴。企業可先確認預計支援的模型、區域、權限治理及承諾消費抵扣方式，再與既有雲端模型服務比較。

02

HeyGen Video：單一提示詞生成影音場景

HeyGen 於 10/21 推出 HeyGen Video，可由文字、圖片或參考素材生成 5 至 15 秒影片，畫面與音訊在同次生成中完成；官方列出 API 與 Creative Studio 皆可使用，解析度最高 2K。它不同於以虛擬人講稿為主的 Avatar 工具，較適合產生場景素材；API 使用需付費，廠商對連續性與指令遵循的描述仍應自行驗證。可用產品、人物與畫面文字等固定條件測試跨鏡頭一致性、聲畫同步及生成成本。

03

Gemini 小型商家工具與商業首頁

Google 於 10/20 宣布 Gemini 將加入商家首頁，可連結 Google Business Profile、Ads、Workspace，以及 Canva、Dropbox、Shopify 等第三方服務；使用者也可上傳品牌素材建立視覺風格，並把表格與收據整理成財務圖表。功能預計數日內向全球 Gemini App 使用者陸續推出，公告未說明各連結服務的完整權限細節。實際使用前應逐項檢查資料授權、品牌素材留存方式與財務分析可追溯性，不把 Google 展示案例當成獨立成效驗證。

Oracle AI Agent Studio for Industry Applications

Oracle 於 10/21 宣布產業版 AI Agent Studio，提供低程式碼／無程式碼環境建立、測試、協調與監控產業代理，支援跨應用流程、MCP 連接和企業權限設定。不過 Oracle 註明此服務預計 12 個月內先在美國推出，其他 OCI Enterprise AI 區域日後擴展；目前不應視為可立即採用。若列入產品評估，先確認正式推出時間、支援的 Oracle 應用與區域，再以測試租戶驗證代理是否遵循既有角色與資料權限。

HeyGen Voice Turbo 免費 API 試用

HeyGen 於 10/21 開放 Voice Turbo API 免費使用至 11/30，使用公用聲線或即時克隆聲線，不需信用卡；免費容量採 best effort，沒有延遲或可用性保證，滿載時可能回傳 429，專業聲線克隆也不包含在內。官方提及的排行榜和盲聽比較來自 HeyGen／其引用的 Artificial Analysis 測試，不宜直接當成自己的語音品質結果。可先用同一段繁中稿比較發音、語氣、延遲與尖峰失敗率，再決定是否趁試用期間整合。

企業代理從選模型延伸到跨系統治理

OpenAI 模型與 Codex 將進入 Google Cloud、Oracle AI Agent Studio for Industry Applications

OpenAI 擴大模型與 Codex 的雲端採購入口，Oracle 則把代理建置放進產業應用流程，兩者都在把模型能力接到企業既有資料、權限與採購制度。

驗證重點分別確認正式可用日期、支援區域、資料邊界、角色權限與計價方式。

影音生成開始以單次產出整合畫面、聲音與旁白

HeyGen Video：單一提示詞生成影音場景、HeyGen Voice Turbo 免費 API 試用

HeyGen Video 將畫面和場景音訊一起生成，Voice Turbo 則提供獨立語音合成 API；前者追求影音場景整體性，後者仍可作為可替換的旁白元件。

驗證重點以相同繁中腳本比較語音辨識度、聲畫同步、內容一致性、延遲和每次可用成本。

商用 AI 逐步靠近小型團隊原有的資料與工作入口

Gemini 小型商家工具與商業首頁、OpenAI 模型與 Codex 將進入 Google Cloud

Gemini 著重把商家資料與行銷工具接進日常助理，Google Cloud 則準備把 OpenAI 模型放入企業採購與開發環境，兩者分別降低小型營運與企業建置的接入門檻。

驗證重點確認帳戶資格、連接器權限、資料能否撤回，以及用量費用是否符合原先的雲端承諾。
