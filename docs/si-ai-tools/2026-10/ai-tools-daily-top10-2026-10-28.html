Liquid AI LFM3 小型多模態模型家族

Liquid AI 於 10/27 開放六款約 2B 級模型，涵蓋文字、影像與影片、語音、視聽整合，以及能輸出機率的決策模型；權重已可從 Hugging Face 取得。文字模型主打本機代理、工具呼叫與 256K context，4-bit 約需 1 GB 記憶體，但採 LFM Open License，不是 Apache 或 MIT。效能數據由 Liquid AI 公布，模型卡也提醒小模型不適合複雜多步推理與代理程式設計；可先依授權及硬體限制，測試自家任務的正確率、延遲和工具呼叫穩定度。

02

OpenAI 與 Oracle 擴大企業 AI 合作

OpenAI 與 Oracle 於 10/27 宣布把 Oracle 應用與資料帶進 ChatGPT，並推出或規劃 AI Security Mesh、AI Workspace、App Composer 與中小企業方案。Oracle AI Workspace 仍在開發中；Oracle 也註明功能、時程與價格可能改變。美國 Oracle 客戶可透過 Marketplace 採購 OpenAI API、Codex 和 ChatGPT Work。評估企業流程前，應確認產品實際開放狀態、資料權限、核准機制，以及應用部署和使用成本。

Microsoft MAI Image 2.7 圖像編修預覽

Microsoft AI 於 10/27 開放 MAI Image 2.7 預覽，可重塑場景風格、調整光線、修改圖片內文字或符號，並修復既有素材；目前可在 MAI Playground 等指定入口試用，文字生成圖片功能尚未推出。Microsoft 引述 Artificial Analysis 評估稱模型在多種編修項目都有進步，這是特定評測結果，不能直接代表各類設計工作。可用同一組商品圖和品牌素材測試局部修改是否保留構圖、文字與細節。
