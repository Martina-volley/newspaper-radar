MiniMax M3.1 Flash

MiniMax 於 10/19 正式推出 M3.1 Flash，現在可經 MiniMax API、M Plan 與 MiniMax Code 使用，權重則尚未釋出。官方稱代理任務用量成本較前代低 70%、線上推論近三倍快，並公布多項代理、程式與電腦操作基準；這些數字來自 MiniMax 自行測試，不能直接推算自有工作負載。現列價為每百萬輸入／輸出 token 0.15／0.60 美元。可先以相同工具與任務比較完成率、延遲、重試及總成本。

02

GitHub Copilot 模型政策 REST API

GitHub 於 10/19 將 Copilot 模型政策的 GET、PATCH REST API 開放正式使用，可在企業、企業團隊、企業應用程式及組織層級查詢或更新模型可用性，並支援把管理權委派到下層。這有助把模型政策納入管理自動化，但錯誤設定也可能影響團隊可選模型。可先以測試組織檢查讀取、更新、權限委派和回復流程，再導入正式政策。

Gemini Skills：App 與 Workspace 推出時程

Google Workspace 團隊 10/13 更新指出，Gemini App 的 Skills 正分批推出，預計 11 月中完成；Google Drive 整合與分享技能仍屬後續規劃。Workspace 版本原訂 10/19 開始 rollout，但官方目前列為延後、尚無新時程，因此不能視為已開始供 Workspace 使用。若正在安排內部試用，先確認帳戶實際入口及管理權限，並把 Workspace 上線時間列為待確認。

GitHub Copilot 舊模型於 10/19 退場

GitHub 已於 10/19 在多數 Copilot 使用介面停用 Gemini 3.7 Flash、GPT-5.5、GPT-5.4、GPT-5.4 mini、GPT-5 mini 與 Grok 4.5，並列出建議替代模型；企業管理員可能需要先啟用替代模型政策。公告最初在 9/18 發出，本期追蹤其正式生效狀態。應盤點模型選擇器與自動化設定，確認替代模型可用，並對常用提示和代理流程做回歸測試。
