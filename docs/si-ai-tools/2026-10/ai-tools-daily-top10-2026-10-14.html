GitHub 情境式密鑰偵測模型

GitHub 於 10/13 說明新的情境式密鑰分類器：先用規則找出疑似憑證，再由微調的 ModernBERT 分類器讀取周邊程式碼，區分真實密鑰與文件範例、測試值等相似字串。GitHub 表示，相較舊流程，警示接受率提高 11.5%、掃描中位時間減少 86%，服務成本降低逾 98%；這些是 GitHub 自家評估，不能直接推算其他程式庫的誤報率。通用密鑰的推送前攔截目前仍在 private preview。可先在自己的 repo 比對漏報、誤報與推送前掃描耗時。

Gemini 4 Argon 擴大開放

Google 於 10/13 開放 Gemini 4 Argon 給全球 Gemini API 開發者與企業，也陸續加入 Google Antigravity、Gemini app、搜尋 AI Mode；同日 GitHub Copilot 宣布此模型 GA，支援多種 IDE 與 Copilot 介面，逐步推出並按供應商牌價計費。Argon 曾在 10/5 日報出現，本期追蹤的是新增的全球使用管道與定價：API 優惠價至 11/30 為每百萬輸入／輸出 token 2／10 美元，之後為 4／20 美元。建議用同一組長程式任務比較完成率、延遲和總成本，並先確認方案資格與管理員模型政策。

GitHub Copilot 企業設定強制更新

GitHub 於 10/13 新增 `forceRemoteSettingsRefresh`，讓企業管理員要求 Copilot CLI、VS Code 與 Copilot app 啟動時重新確認伺服器政策；無法確認最新設定時會停止執行，不沿用過期快取。GitHub 也開始要求 `sandbox` 管理設定使用者更新至最低支援版本。這讓企業政策能更即時生效，但網路或服務中斷時可能影響啟動；應先在測試群組驗證政策更新、離線啟動與舊版客戶端的行為。
