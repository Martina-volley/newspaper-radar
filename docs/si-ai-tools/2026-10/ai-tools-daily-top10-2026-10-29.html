01

GitHub Copilot Fusion 正式推出

GitHub 於 10/28 將 Copilot Fusion 轉為正式版，使用者選擇工作強度後，由系統依任務路由並編排模型，可採單模型、先草擬再升級檢查，或由另一模型檢視後修訂等方式。Fusion 已在 VS Code、Copilot app、CLI 和 JetBrains 提供；每個模型仍按各自標準費率計費，付費方案目前有期限優惠。官方公布的速度與成本數據來自指定評測；可用固定程式任務實測品質、延遲、模型選擇透明度與總帳單。

02

GitHub Agentic Workflows 正式推出

GitHub Next 的開源 Agentic Workflows 於 10/28 正式提供，開發者以 Markdown 描述 issue 分流、CI 故障分析、文件更新或測試撰寫等工作，再由工具轉成 GitHub Actions。可使用 Copilot 或自選程式代理，並沿用現有 runner 與政策；代理預設唯讀，在沙箱及防火牆內執行，提出的變更還會經安全輸出與威脅掃描。免費、Team 和 Enterprise 均可使用；正式導入前，應驗證工作流程權限、token 預算及自動提出變更的審核方式。

03

Claude for Legal 法律工作 Artifacts

Anthropic 於 10/28 為 Claude for Legal 推出可改用自有資料與連接器的互動式法律工具範本，涵蓋合約檢視、法規追蹤及法律需求收件；輸出會附來源連結，並可在企業內分享。這些範本適合產生可供律師審閱的初稿或工作面板，不代表法律結論可免人工確認。試用時應檢查引用是否能回到原文、跨團隊分享是否遵守倫理牆與資料權限。

04

Claude Enterprise 智慧報告、問卷與共用預算

Anthropic 於 10/28 將三項企業管理功能轉為正式版：智慧報告整理團隊工作、用量與成本；內嵌問卷收集使用者回饋；共用預算讓群組共享每月額度，並保留個人上限。智慧報告會抽樣分析對話並列出工作流程和摩擦點，官方明確表示不應用來評估個人績效或作人事決定；功能也會受 HIPAA、客戶管理金鑰等設定影響。管理員可先核對抽樣與保留設定，再確認報告用途、預算警示和加額審批流程。

05

ChatGPT 連接 iCloud Mail 與 Calendar

OpenAI 於 10/27 宣布，ChatGPT 可連接 iCloud Mail 與 Calendar，協助搜尋郵件、整理收件匣、查看行程及更新日曆事件；官方列為網頁、桌面與 iOS 全方案可用。兩項服務需分別連接，設定時使用 Apple app 專用密碼。使用前可先確認連接帳號、可執行的郵件或行事曆動作，以及撤銷連線的方法，再以低風險資料測試。

06

OpenAI 與 ServiceNow 擴大工作流程整合

OpenAI 與 ServiceNow 於 10/28 擴大合作，ServiceNow MCP 外掛已可在 OpenAI Marketplace 取得；使用者可在 ChatGPT 中查找相似 IT 事件、評估變更風險並更新 ServiceNow 記錄，權限依客戶的 ServiceNow 設定執行。安全、語音與 Codex 整合仍分階段規劃，部分預計至 2027 年才推出。企業評估時可先確認外掛目前授權的動作，再於測試環境檢查記錄更新、核准與稽核軌跡。

模型選擇與代理工作流程開始由平台統籌

GitHub Copilot Fusion、GitHub Agentic Workflows

Fusion 依任務安排模型，Agentic Workflows 則把代理任務編入 Actions；兩者把開發者的工作由逐步操作推向可持續編排。

驗證重點量測每類任務的成功率、耗用成本、人工覆核量與錯誤回復方式。

AI 助理逐步接上專業資料與業務系統

Claude for Legal、ChatGPT iCloud 連接器、OpenAI／ServiceNow

法律工具、個人郵件日曆與 IT 服務紀錄都開始進入對話式工作流程，能否安全採取下一步取決於資料權限與使用者核准。

驗證重點以測試帳號檢查來源引用、最小權限、可執行動作、分享邊界及撤銷連線。

企業開始把 AI 成效與預算放在同一個管理循環

Claude Enterprise 智慧報告與共用預算、GitHub Agentic Workflows

管理者可用使用情況與預算規劃擴大採用，而代理自動化也需同步設定額度、執行權限及審核責任。

驗證重點確認報告資料用途、token 預算、支出警示與人員覆核節點。
