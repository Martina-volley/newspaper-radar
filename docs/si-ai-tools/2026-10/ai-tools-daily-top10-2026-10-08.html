焦點

01

Claude Haiku 5.5

Anthropic 於 10/7 發布 Haiku 5.5，現在可透過 Claude Platform 與主要雲端平台使用，適合高頻摘要、分類、客服及代理子任務。官方稱相較 Haiku 4.5，平均執行成本約低 75%；這是 Anthropic 的比較結果，實際節省幅度會隨提示長度與工作流程改變。可先用自家標註資料測準確率、延遲與每項成功任務的成本。

02

ChatGPT Intelligent UI

OpenAI 於 10/7 開始在 ChatGPT 推出互動式回答：模型可依問題產生圖解、比較介面或可直接操作的小工具，也能邊思考、邊先回覆部分內容。付費方案先行，Free 與 Go 自 10/8 起擴大推出；Enterprise 仍受管理員設定影響。這會改變回答的呈現方式，但輸出仍需核對資料正確性、可操作性與無障礙需求。

03

OpenAI Decisions API

OpenAI 於 10/6 開放 Decisions API 公開測試版，讓 `gpt-6-luna` 對文字或圖片輸入回傳條件機率、固定選項或分級評分，適用於分類、路由與優先排序。官方稱相較 Responses API 最快可達 10 倍速度；目前只支援 Luna，且仍在 beta。應以標註資料設定門檻，測量誤判成本，再決定哪些結果可自動執行、哪些要交由人員覆核。

04

Anthropic Cyber Verification Program

Anthropic 於 10/6 擴大資安驗證計畫，分成不同存取層級，讓通過資格與控制條件的資安團隊申請使用降低部分阻擋的模型能力；公告列出 Opus 5.5、Sonnet 5.5、Mythos 5.1 與後續模型。這是受審核的防禦用途方案，並非一般帳號的模型開關。申請前先確認使用範圍、存取治理、稽核與資料處理要求。

1 則
05

ChatGPT 音訊上傳

ChatGPT 於 10/6 開放音訊檔上傳，可產生逐字稿、整理錄音摘要，或回答音檔內容問題，適用於會議、訪談與課程紀錄。功能目前提供給付費訂閱與工作區，實際可用性會受地區、工作區設定、版本與模型影響；逐字稿也可能出錯，且語言表現不一。正式用於紀錄前，應抽查專有名詞、說話者與關鍵數字。

Claude Haiku 5.5 ＋ OpenAI Decisions API

Haiku 5.5 主打高頻的一般任務，Decisions API 則把輸出限制成選擇或評分；先縮小任務與答案形狀，可能比單純更換大模型更容易控制成本。

AI 回答正從文字走向可操作介面

ChatGPT Intelligent UI ＋ OpenAI Decisions API

Intelligent UI 把結果變成使用者可操作的介面，Decisions API 則把判斷結果變成程式可讀的型別；兩者分別處理人機互動與系統整合。

驗證重點檢查介面是否忠實呈現來源，以及 API 的信心與錯誤是否能觸發人工覆核。

高風險任務需要分級開放

Claude Haiku 5.5 ＋ Anthropic Cyber Verification Program

一般可用模型仍保留較嚴格的資安限制，通過審核的防禦團隊才可申請較高權限，能力供應與使用者資格開始一起設計。

驗證重點核對申請條件、模型清單、稽核方式與資料保留規則是否符合團隊政策。

多模態輸入與互動輸出一併擴大

ChatGPT 音訊上傳 ＋ ChatGPT Intelligent UI

使用者可以把錄音交給 ChatGPT 整理，再以圖解或互動方式理解答案；但輸入轉錄與生成介面各自都可能帶入錯誤。

驗證重點抽查轉錄內容，並確認互動介面中的數字、引用與操作結果。
