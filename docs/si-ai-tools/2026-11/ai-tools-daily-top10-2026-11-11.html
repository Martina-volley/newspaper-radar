Businesses in ChatGPT：商家資料管理與 Business Agent Beta

OpenAI 於 11/10 推出 Businesses in ChatGPT Beta，商家可透過 Business Hub 認領商家資訊、管理內容並查看使用者在 ChatGPT 中的互動洞察；符合資格的電商與線上服務商家也可建立 Business Agent，回覆顧客問題並協助探索商品。Business Agent 對話會清楚標示，並與 ChatGPT 的獨立回答分開；目前僅向美國符合資格的商家開放。商家可先確認所屬類別與認領資格，再檢查資訊正確度、代理回答邊界及導流成效。

Gemini 4 Carbon 正式加入 GitHub Copilot

GitHub 於 11/10 將 Gemini 4 Carbon 加入 Copilot，供 Pro+、Max、Business 與 Enterprise 使用者選用，適用於 VS Code、Visual Studio、CLI、Coding Agent、JetBrains、Xcode 等介面；現正分批開放。模型採依供應商牌價計費，企業管理員可透過模型政策調整存取。Gemini 4 Carbon 曾於 10/30 登上選報，本次追蹤的是它新增 Copilot 通路，不重述模型發布。啟用前可確認方案及管理員設定，並以既有程式任務比較品質、耗用與費用。

03

GitHub Copilot CLI 的 C++ 語言伺服器自動設定 MSBuild

GitHub 於 11/10 將 MSBuild 編譯指令擷取器直接整合進 Microsoft C++ Language Server；開啟 MSBuild 專案時，Copilot CLI 會自動產生語言伺服器所需的編譯資料庫，不再需要先找設定 skill 或自行準備 `compile_commands.json`。此變更只涵蓋 MSBuild；CMake 與自訂建置系統仍需各自設定，並須安裝外掛、接受授權條款及具備 Copilot 訂閱。C++ 團隊可用既有專案核對資料庫是否正確涵蓋組態、標頭檔與建置旗標，再檢查跳轉與參照結果。
