OpenAI GPT‑6 Cyber：限授權範圍的資安研究模型

OpenAI 於 11/5 發表 GPT‑6 Cyber，主打弱點探索、漏洞驗證與修補，並稱模型在其 ExploitGym 評測得分 48.5%，較 GPT‑5.6 Cyber 的 32.1% 高；OpenAI 也公布 Linux、Firefox 研究案例。這些基準與案例由 OpenAI 提供，不能直接當作第三方重現結果。模型目前只向通過核准的 Daybreak Red 客戶逐步開放，尚非一般 API 使用者可申請即用。適用團隊應先核對資格、授權範圍、沙箱隔離與人工審查，再用自有程式庫測量可重現性和誤報率。

OpenAI Images 2.6：更快生成、GIF 與精準編修

OpenAI 於 11/4 將 Images 2.6 帶進 ChatGPT、Codex 與 API，支援用提示或草圖製作循環 GIF；ChatGPT 也推出參考圖片保存功能，API 增加區域標記、SVG 匯出及調整場景規劃程度的參數。官方稱生成速度較前版快 50%，這是供應商測試結果；GIF 功能仍在 ChatGPT 分批推出。可用同一組品牌素材比較生成時間、跨輪角色／產品一致性、編修命中率與實際可用的輸出格式。

03

GitHub Dependabot 支援 Agent Package Manager（APM）版本更新

GitHub 於 11/3 讓 Dependabot 一般提供 APM 版本更新：依 `apm.yml` 的 Git 相依項目定期開 PR，並在存在時更新 `apm.lock.yaml`，用來維護 agent skills、提示與指令套件。功能已在 github.com 對所有方案開放，GitHub Enterprise Server 3.24 才會支援；目前處理的是版本更新，不包含安全更新。團隊可先檢查產生的 PR 是否保留審查流程，並確認套件來源、版本鎖定與升版測試。
